# Sprint 05 – Building Complete Business Transactions with SOQL, DML and Apex

## 📌 Overview

Sprint 05 focuses on implementing a complete Placement Management System using Salesforce Apex. The project demonstrates how SOQL retrieves business information, how DML modifies records, and how both are combined to complete a real business transaction.

---

## 🎯 Objectives

- Retrieve Student information.
- Retrieve Job information.
- Prevent duplicate applications.
- Create new Application records.
- Update Application status.
- Complete the end-to-end business transaction.
