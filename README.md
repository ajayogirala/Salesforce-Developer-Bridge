## 1. What is LWC?

Lightning Web Components (LWC) is Salesforce's modern user interface framework built on web standards such as HTML, JavaScript, and CSS. It is used to create reusable, fast, and responsive components for Salesforce applications.

---

## 2. What did you build?

I built the first user interface for a Library Management System using Lightning Web Components.

The component displays:

- Library Management System title
- Welcome message
- Today's Date
- Librarian Name
- Library Name
- Department
- Library Statistics
- Number of Books
- Books Issued
- Total Members
- Show Welcome Message button
- Issue Book button
- Dynamic Status update using JavaScript

The component uses hard-coded values and demonstrates data binding and event handling without using Apex or a database.

---

## 3. Which file contains HTML?

The HTML code is stored in:

libraryHome.html

This file defines the user interface, including the page layout, headings, labels, buttons, and displayed information.

---

## 4. Which file contains JavaScript?

The JavaScript code is stored in:

libraryHome.js

This file contains:

- Variables
- Methods
- Event handling
- Status updates
- Welcome message logic
- Data binding
