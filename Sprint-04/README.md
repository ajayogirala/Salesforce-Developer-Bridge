# Sprint 04 – Lightning Web Components (LWC)

## Overview

This sprint focuses on building the first Lightning Web Component (LWC) named **libraryHome**. The component was developed using HTML, JavaScript, and Metadata Configuration, then deployed to Lightning App Builder.
