# bookChild

## Purpose
Receives data from the parent component and sends events back to the parent.

### Responsibilities

- Receives Book Id using @api.
- Displays the selected book.
- Fires a custom event when the **Issue Book** button is clicked.

### Files

- bookChild.html
- bookChild.js
- bookChild.js-meta.xml

### Concepts Used

- Child Component
- @api Decorator
- Custom Events
