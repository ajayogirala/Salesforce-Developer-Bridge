# Validation Rules

## Overview

Validation Rules ensure only valid Book Issue records are saved.

## Rules Implemented

- Book_Available
- Book_Required
- Check_Return_Date
- Invalid_Return_Date
- Member_Required

## Purpose

- Prevent duplicate book issues.
- Validate Issue Date and Return Date.
- Ensure Book selection.
- Ensure Member selection.
- Improve data quality.
