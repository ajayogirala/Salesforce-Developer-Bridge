# Check_Return_Date Validation Rule

## Purpose

Ensures that the Return Date is always later than the Issue Date.

## Formula

```text
Issue_Date__c > Return_Date__c
```

## Error Message

Return Date must be after Issue Date.

## Error Location

Top of Page

## Learning Outcome

- Prevents invalid return dates.
- Maintains data consistency.
- Uses Validation Rules instead of Apex.
